# **App Name**: BreadMate

## Core Features:

- Hero Carousel: Display a full-width background hero carousel on the homepage featuring high-quality bread images, titles, and short descriptions.
- Product Sales Section: Showcase bread products using Shadcn Cards with images, names, descriptions, prices, and 'Add to Basket' buttons.
- Gallery: Display a responsive grid gallery featuring photos of the bread-making process and customer favorites.
- Navigation Bar: Implement a minimalist navigation bar with a logo, brand name, order page link, contact page link, and dynamic 'Sign In / Sign Out' link based on Firebase auth state.
- Checkout Page: Provide a dedicated checkout page to the users. This page should have editable delivery address and a PayPal checkout.
- Authentication: Provide users the possibility of sign-in using Firebase authentication with email/password

## Style Guidelines:

- Primary color: Warm bread color (#A66321) to evoke the comforting and rustic nature of bread-making.
- Background color: Light beige (#F5F5DC) for a soft, inviting backdrop.
- Accent color: Burnt orange (#CC7722) to highlight calls to action and important information.
- Headline font: 'Playfair', a modern serif with an elegant feel. Body font: 'PT Sans' (sans-serif) to create a balanced, readable layout, well suited to blog style text.
- Use simple, line-based icons related to baking, ingredients, and navigation.  Ensure that they are appropriate for mobile displays.
- Employ a clean, grid-based layout to ensure responsive design across all devices. Use white space to allow for good readability.
- Implement subtle transitions and animations to enhance user engagement. For example, use animations when adding items to the cart.
